## Решения по конфликтам

- **Повторения и «Редактура».** Повторения — вариант письменного перевода, а не переименованная «Редактура».
  Старые работы «Редактура» не трогались. Отключить «Редактуру» для новых работ можно в настройках (Q37).
- **Устный перевод.** Две услуги в базе остались, тарифы и исполнители привязаны к их кодам. Объединены только в форме.
- **Срок работы.** В таблицах v3 его нет. Срок задаётся на заказе, работы без своего срока получают срок заказа при создании.
  Старые сроки работ сохраняются и видны в свёрнутом блоке.
- **Тематика.** Работы хранят текст. Старая тематика вне справочника показывается с пометкой «не из справочника» и не теряется.

## Миграции

- `0029_order_deadline_mode` — `orders.deadline_manual`, `deadline_time_mode`, `deadline_time` (default `false` / `''`).
- `0030_work_v3_fields` — у работ `character_count_source`, `measured_character_count`, `final_character_count`,
  `final_volume_at`, `document_names`, `document_names_source`; `order_files.work_id` (nullable FK);
  таблица `topic_catalog` + идемпотентный seed 31 тематики.

Обе миграции проверены на копии локальной PostgreSQL 17: `upgrade → downgrade 0028 → upgrade`.
На копию в схеме 0028 вставлен исторический заказ. После upgrade его срок, цена и объёмы не изменились,
новые поля получили «старые» значения (`deadline_manual=false`, режим и источник `''`), тематик ровно 31 без дублей.
Копия удалена. Миграции на production **не применялись**.

## Деплой в production (только после разрешения)

Изменены backend, frontend и есть миграции. Backend применяет миграции при старте, поэтому бэкап идёт первым.

```powershell
ssh -i "$HOME\.ssh\lingvo_beget_manual_20260914" root@159.194.208.185
```

Дальше на сервере (bash):

```bash
cd /opt/lingvo-connect-admin
docker exec lingvo-connect-crm-postgres-1 sh -c 'pg_dump -U "$POSTGRES_USER" -Fc "$POSTGRES_DB"' > /root/lingvo-backups/before_paid_package_$(date -u +%Y%m%dT%H%M%SZ).dump
git fetch origin && git merge --ff-only origin/main
docker compose -p lingvo-connect-crm --env-file .env -f docker-compose.prod.yml -f compose.beget.yml up -d --build backend frontend
docker exec lingvo-connect-crm-backend-1 alembic current   # ожидается 0030_work_v3_fields (head)
```

Откат: сначала `docker exec lingvo-connect-crm-backend-1 alembic downgrade 0028_client_tariffs` (пока запущен новый код),
затем `git checkout a384caf` и та же команда `docker compose … up -d --build backend frontend`.
Если что-то пошло не так с данными — восстановить дамп `before_paid_package_*.dump` через `pg_restore`.
