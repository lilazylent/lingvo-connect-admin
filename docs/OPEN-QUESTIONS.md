# Вопросы клиенту перед реализацией

Ниже 30 вопросов. Они сформулированы без технического жаргона и сгруппированы по моменту, когда ответ становится обязательным.

## Решено перед Phase 1 (Q01–Q05)

1. **Q01 — RESOLVED.** На этапе разработки доступ только у владельца. Первый ADMIN создается безопасной bootstrap-командой; сотрудников клиента создает ADMIN после передачи.
2. **Q02 — RESOLVED.** В MVP используются только роли `ADMIN` и `MANAGER`.
3. **Q03 — RESOLVED.** MANAGER работает со всеми операционными заявками, клиентами, заказами, комментариями, файлами и назначениями. Управление пользователями, ролями, глобальными тарифами, system/security settings и destructive administrative actions запрещено и проверяется backend.
4. **Q04 — RESOLVED.** MANAGER видит все Applications, Clients и Orders. Ограничения `only_assigned`, team и department сейчас не реализуются.
5. **Q05 — RESOLVED.** TOTP 2FA и обязательная смена первого/сброшенного пароля входят в MVP.

## Самые критичные ответы

Q01–Q05 закрыты и реализованы в security foundation Phase 1. Для безопасного проектирования заявок и заказов до начала соответствующего этапа нужны Q06–Q13. Финансовую автоматизацию нельзя начинать без Q19–Q24, а загрузку клиентских файлов — без Q25–Q27.

Отсутствие ответа не разрешает подставлять вымышленное бизнес-правило. Допустимо реализовать только технический каркас, явно оставив зависимый модуль выключенным.
