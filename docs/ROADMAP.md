# Lingvo Connect CRM — общий roadmap

Единый журнал статусов. История не удаляется: новые этапы дописываются сверху своей секции,
детальные отчёты лежат в корне репозитория (`PHASE_*_REPORT.md`, `BUGFIX_SPRINT_*`, `PAID_PACKAGE_*`).

Статусы: `DONE/VERIFIED` — реализовано и проверено тестами; `IMPLEMENTED/NOT VERIFIED` — реализовано,
нужна ручная проверка владельцем; `TODO`; `BLOCKED` — с причиной; `DECISION REQUIRED` — нужен выбор Олега.
