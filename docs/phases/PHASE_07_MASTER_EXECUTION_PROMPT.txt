A local visual patch is forbidden when the same semantic pattern exists
elsewhere.


======================================================================
4. DO NOT PATCH SYMPTOMS
======================================================================

Do NOT solve visual defects with arbitrary page-specific overrides.

Avoid:

- unnecessary !important
- random margin-left / top values
- page-specific colors where semantic tokens should exist
- extra stylesheets layered over unresolved legacy CSS
- hiding overflow to conceal broken layout
- duplicate buttons implemented differently across pages
- hard-coded white text to fix one Dark screen
- deleting valid information just to satisfy Playwright
- changing tests to accept broken UI

For every defect, identify its source category first:

A. Design token problem
B. Shared primitive problem
C. Shared component problem
D. Layout contract problem
E. Page composition problem
F. CSS cascade / legacy override problem
G. Data semantics problem
H. Browser/native-control problem

Fix the root cause.
